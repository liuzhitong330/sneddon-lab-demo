# Sneddon Lab research demo

An interactive, paper-grounded evidence map of pancreatic endocrine lineage commitment, prepared by Cathy Liu for the Sneddon Lab at UCSF.

The demo organizes reported results from Byrnes et al. (2018) and the public GSE101099 record. It is a structured reading of published evidence, not a raw-data reanalysis.
